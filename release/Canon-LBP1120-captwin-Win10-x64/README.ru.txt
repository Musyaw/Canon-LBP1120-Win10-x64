================================================================================
  Canon Laser Shot LBP-1120 — печать на Windows 10/11 (64-bit)
  Комплект CAPT v1.1.2 (captwin)
================================================================================

ЧТО ЭТО

  Canon не выпускала 64-bit CAPT-драйвер для LBP-1120. На современном Windows
  принтер по USB виден, но без CAPT печать из программ невозможна.

  Этот комплект добавляет:
    - прямую печать на USB (протокол CAPT v1, сжатие SCoA);
    - очередь Windows «Canon LBP1120 (CAPT)» и сервер на 127.0.0.1:9100;
    - печать из браузера и Office через Ctrl+P (PostScript -> Ghostscript -> CAPT).

  Не является официальным продуктом Canon.


НА КАКИХ ПРОЕКТАХ ОСНОВАНО

  1) libcapt (darkvision77)
     https://github.com/darkvision77/libcapt
     Реверс протокола CAPT v1, упаковка SCoA, работа с принтером на уровне
     команд и растра. Лицензия: BSD-2-Clause.

  2) captppd (darkvision77)
     https://github.com/darkvision77/captppd
     USB-бэкенд для CUPS/libcapt (libusb). В этом комплекте использован как
     основа доступа к устройству 04A9:262B. Лицензия: BSD-2-Clause.

  3) libusb
     https://github.com/libusb/libusb
     Доступ к USB под Windows (с WinUSB). Лицензия: LGPL-2.1 (исходники libusb
     включены в дерево сборки проекта).

  4) Ghostscript (Artifex, GPL)
     https://ghostscript.com/
     Конвертация PostScript из очереди Windows в растр PBM для captwin.
     Устанавливается установщиком автоматически, если ещё нет в системе.

  5) Zadig / libwdi (опционально)
     tools\zadig.exe — если INF WinUSB не ставится, вручную WinUSB для
     VID_04A9 PID_262B. Лицензия: GPL-3.

  Другие упоминания (captdriver и т.п.) для LBP-1120 в открытом виде не
  подходили; связка libcapt + captppd — рабочая для CAPT v1 / LBP-1120.


ЧТО БЫЛО СДЕЛАНО В ЭТОМ РЕЛИЗЕ

  Программа captwin.exe (C++, MinGW, Windows x64):
    list          — список USB-устройств CAPT
    status        — статус принтера
    testpage      — тестовая страница (PBM 600 dpi)
    print         — печать файла PBM (формат P4)
    serve         — TCP-сервер 127.0.0.1:9100 для заданий из Windows

  Установка и окружение:
    - WinUSB через INF (captwin_winusb.inf) или Zadig
    - автоматическая установка Ghostscript
    - очередь «Canon LBP1120 (CAPT)», драйвер Microsoft PS Class Driver,
      порт TCP 127.0.0.1:9100
    - установщик Canon-LBP1120-CAPT-Setup.exe (Inno Setup)
    - окно «Сервер печати» (GUI, без чёрной консоли): статус, лог, тест,
      кнопка «Настроить принтер»

  Исправления по ходу разработки:
    - WinUSB вместо usbprint (libusb не открывал устройство)
    - запуск Ghostscript с путями, содержащими пробел (Program Files)
    - размер страницы 4960x7016 px и выравнивание PBM (ширина кратна 8)
    - надёжное создание очереди Windows (prnms005.inf)

  Ограничения:
    - Пока активен WinUSB на USB, стандартный драйвер Canon для этого же USB
      не используется; печать на железо идёт через captwin.
    - Цвет с экрана печатается как оттенки серого.
    - Сложные PDF/страницы зависят от Ghostscript.

================================================================================
  КАК УСТАНОВИТЬ И ПЕЧАТАТЬ
================================================================================

ВАРИАНТ А — установщик (рекомендуется)

  1. Подключите LBP-1120 по USB, включите принтер, положите бумагу.

  2. Правый клик по Canon-LBP1120-CAPT-Setup.exe -> Запуск от имени
     администратора.

  3. Дождитесь окончания мастера (Ghostscript, WinUSB, принтер Windows).
     При необходимости отметьте «Запустить сервер печати».

  4. На рабочем столе откройте ярлык «Canon LBP1120 — печать».
     В окне должно быть:
       Сервер: работает — 127.0.0.1:9100
       Ghostscript: установлен
       Принтер Windows: Canon LBP1120 (CAPT)
     Если принтер красный — нажмите «Настроить принтер» (подтвердите UAC).

  5. Печать:
       - из браузера / Word: Ctrl+P -> Canon LBP1120 (CAPT);
       - тест: кнопка «Тестовая страница» в окне сервера.
     Окно сервера не закрывайте во время печати из Ctrl+P.

  6. Если после установки WinUSB принтер «пропал» с USB: отключите кабель
     на 5 секунд и подключите снова. При ошибке INF — tools\zadig.exe,
     устройство 04A9:262B, драйвер WinUSB.


ВАРИАНТ Б — portable (без Setup.exe)

  1. Папка Canon-LBP1120-captwin-Win10-x64.

  2. От администратора: Setup.bat (то же, что делает установщик, в
     Program Files\CanonLBP1120Capt).

  3. CaptWin-Server.bat или Launch через ярлык после Setup.

  4. Ctrl+P или print-testpage.bat.


УДАЛЕНИЕ

  Параметры -> Приложения -> Canon LBP1120 CAPT -> Удалить.
  Снимаются файлы программы, очередь принтера и порт 9100.
  Ghostscript в системе может остаться — удалите отдельно, если не нужен.

  Если очередь осталась в «Принтеры и сканеры»: Удалить устройство у
  Canon LBP1120 (CAPT) или Setup-PrinterQueue.bat от администратора
  (в каталоге программы после установки).


КОМАНДЫ captwin (из папки с exe)

  captwin.exe list
  captwin.exe status
  captwin.exe testpage
  captwin.exe print файл.pbm
  captwin.exe serve --port 9100

  USB ID по умолчанию: 04a9:262b
