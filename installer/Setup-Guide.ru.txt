Canon LBP1120 CAPT — краткая настройка после установки
=====================================================

Папка программы (пример):
  C:\Program Files\CanonLBP1120Capt

Уже сделано установщиком:
  • captwin, Ghostscript (папка gs\), ярлык «LBP-1120 — быстрый запуск»
  • Попытка создать принтер «Canon LBP1120 (CAPT)»

Что нужно сделать вручную (один раз):

1) USB + WinUSB (Zadig)
   Файл: tools\zadig.exe
   Options → List All Devices
   Устройство: Canon LBP-1120 / VID_04A9 PID_262B
   Драйвер: WinUSB → Replace Driver
   После Success: USB отключить 5 сек, снова подключить.

2) Принтер Windows (если нет в списке)
   Файл: Setup-PrinterQueue.bat (от администратора)

3) Сервер
   Ярлык на рабочем столе: LBP-1120 — быстрый запуск
   Все три индикатора зелёные → «Готов к печати»

4) Печать
   • Тестовая страница в окне сервера
   • Браузер: Ctrl+P → Canon LBP1120 (CAPT)

Повторный мастер: installer\PostInstall-Wizard.ps1
